# 13 phương án giờ sinh — 19/01/2001

Website tham khảo Tử Vi cho nam sinh ngày 19/01/2001 tại Hà Nội. Gồm 12 giờ địa chi và biến thể Tý muộn; bảng so sánh Mệnh, công việc, tiền bạc, tình duyên, sức khỏe, xuất ngoại, gia đình, điền sản.

- Mở website khi GitHub Pages được bật: https://ngngoc5201-boop.github.io/tuvi-12-gio/
- File chính: `index.html`.

**Lưu ý:** Nội dung là diễn giải theo hệ thống Tử Vi truyền thống, không dùng làm căn cứ xác minh giờ sinh thực tế hay dự đoán y khoa, tài chính.
